# A/B-тест сервиса доставки

## О проекте

Анализ результатов A/B-теста сервиса доставки.

Цель исследования — определить, повлияло ли тестовое изменение на конверсию пользователей и другие продуктовые метрики.

## Основные задачи

- провести первичный анализ данных;
- проверить качество и сопоставимость групп;
- рассчитать конверсию;
- оценить абсолютное и относительное изменение;
- проверить статистическую значимость конверсии;
- сравнить средний чек;
- проанализировать повторные заказы;
- провести сегментный анализ по устройствам.

## Стек

- Python
- pandas
- NumPy
- Matplotlib
- SciPy
- statsmodels

## Статистические методы

Для анализа использовались:

- двухвыборочный z-тест для пропорций — для сравнения конверсии;
- t-тест Welch — для сравнения среднего чека.

Уровень значимости: **α = 0.05**.

## Основные метрики

- Conversion Rate;
- Average Order Value;
- Delivery Price;
- Time to Order;
- Retention / повторный заказ.
